## 🔧 Proyecto actual: LA BLANCA 360

Plataforma de gestión de bodas para un negocio real de eventos. **En desarrollo** (repositorio privado hasta la defensa del proyecto, junio de 2027).

- **Backend:** Java 21, Spring Boot, Spring Security, JPA/Hibernate, MySQL 8 y Flyway
- **Aplicaciones:** web (Thymeleaf), escritorio (JavaFX) y Android
- **Funcionalidades:** reservas, presupuestos dinámicos y configurador visual de bodas
- **Forma de trabajo:** arquitectura por capas (Controller → Service → Repository), Git y Scrum
